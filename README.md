# UniPath

Práctica #1 del curso Ambiente Web Cliente Servidor.

## Descripción

UniPath es una propuesta de aplicación web orientada a ayudar a estudiantes
universitarios a planificar las materias de su carrera tomando en cuenta
materias aprobadas, prerrequisitos y disponibilidad.

## Tecnologías

- HTML5
- CSS3
